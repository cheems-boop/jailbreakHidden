# 越狱隐藏环境新版
>该方案可在 zygisknext + 月虹模块 + lsp +fusehide隐藏无效的状态下推荐使用
>目前该方案仅在OPace5u上测试表现为接近完美环境，因为OPace5u使用月虹的老方案表现为，Permission loophole 发现magisk运行痕迹 等多项报错
>如果以后模块的版本更新了，就不一定能达到这种效果
>文件中的README.md不一定是准确的,按照这里的来
>还有，要认真观看，有一些细节必须遵守，该教程并不绝对，如果你能简化更好，可能存在漏洞，自己注意

---

## 以下是正文内容
1. 使用月虹提权/ghostlock，或其他方案提权ksu
2.  `安装软件`并`刷入用户模块`过程：
```
1. fusehide
2. neozygisk(这里需要热重启一次)
3. lsp
4. HMA-oss(这个后来自己配置，该文章不会写)
5. cq-uid-seccomp
```
3. `冷重启`重新越狱
>该步骤是为了激活lsp&HMA-oss，如果你的软重启已经达到了可以正常使用的目的，不需要此步骤
>如果不行，则放弃此方案


4. 打开lsp，激活fusehide
>这里不需要重启，只需要来回，选择媒体重复优化和强行停止，直到在fusehide(application)内显示已激活为止，如果怎么的也不行，可以软重启

5. 配置fusehide,具体步骤如下
```
1. 点击配置
2. 点击右上角的设置
3. 将可见例外中的Android MT2删掉如果有
4. 右上角保存
5. 选择检测软件之类的，比如春秋检测(com.chunqiunativecheck)启动隐藏，右上角点击确认
```

6. 配置cq-uid
>点击执行按钮，添加包名即可
>这里的`包名`指的是检测软件之类的

7. 刷入月虹模块
>此过程，出现选择模式，选择搞机模式
>此过程，出现`仅做基础配置相应的`和`下载lsp zygisknext`选`"前者"`，具体表现为`音量下键`

8. 刷入完成之后进行如下操作：
```
1. 看看是否月虹模块提示正常
2. 正常则摁过检测软重启
3. 不正常则重刷软重启
```
>这里说的正不正常的指标指的是，webui界面，出现`就绪`绿色提示
>接下来的每一次重启全部使用，月虹的过检测软重启

## 补充：
>如果你刷不了月虹，也可以刷`免解刷我`代替，不过不推荐，刷完以后要用这个模块的执行重启，具体模块在春秋二群
