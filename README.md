# 越狱隐藏环境教程（新版）

> 本次更新已彻底取代月虹模块。
> 注意：若日后相关模块版本更新，效果可能无法保证与本文一致。
> 请认真阅读全文，部分细节必须严格遵守。本教程并非绝对标准做法，若你能自行简化更好，但简化后可能存在漏洞，请自行留意。

## 正文

### 1. 提权 KernelSU
使用月虹提权 / ghostlock，或其他任意方案完成 KSU 提权。

### 2. `安装软件` 并 `刷入用户模块`
按以下顺序依次刷入：

1. fusehide
2. JailNotBreak
3. neozygisk（此处需要热重启一次）
4. LSP
5. HMA-oss（该模块需自行配置，本文不再赘述）
6. kill-uid-seccomp

### 3. `冷重启` 后重新越狱
> 此步骤用于激活 LSP 与 HMA-oss。若软重启后已能正常使用，可跳过此步骤。
> 若仍不行，则放弃本方案。

### 4. 打开 LSP，激活 fusehide
> 此处无需重启，只需来回操作：选择「媒体重复优化」并「强行停止」，反复进行，直到 fusehide(application) 内显示「已激活」为止。
> 若无论如何都无法激活，可尝试软重启。

### 5. 配置 fusehide
具体步骤如下：

1. 点击「配置」
2. 点击右上角的「设置」
3. 若「可见例外」中存在 Android MT2，将其删除
4. 点击右上角「保存」
5. 选择检测软件（例如春秋检测）启动隐藏，点击右上角「确认」

### 6. 配置 kill-uid
> 点击「执行」按钮，选择检测软件并保存。

### 7. 隐藏越狱模式
在 KSU 模块管理界面，点击「隐藏越狱模式」左下角的「执行」。

> 注意：该模块是通过 zygote 重启来实现隐藏功能的，并非真正意义上的软重启。
> 若需要加载模块，请先使用 KSU 自带的软重启重启一次，然后再使用此重启。
