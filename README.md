# 越狱隐藏环境新版
>本次更新，彻底代替了月虹模块
>如果以后模块的版本更新了，就不一定能达到这种效果
>还有，要认真观看，有一些细节必须遵守，该教程并不绝对，如果你能简化更好，可能存在漏洞，自己注意

---

## 以下是正文内容
1. 使用月虹提权/ghostlock，或其他方案提权ksu
2.  `安装软件`并`刷入用户模块`过程：
```
1. fusehide
2. JailNotBreak
3. neozygisk(这里需要热重启一次)
4. lsp
5. HMA-oss(这个后来自己配置，该文章不会写)
6. cq-uid-seccomp
```
3. `冷重启`重新越狱
>该步骤是为了激活lsp&HMA-oss，如果你的软重启已经达到了可以正常使用的目的，不需要此步骤
>如果不行，则放弃此方案


4. 打开lsp，激活fusehide
>这里不需要重启，只需要来回，选择媒体重复优化和强行停止，直到在fusehide(application)内显示已激活为止，如果怎么的也不行，可以软重启

5. 配置fusehide,具体步骤如下
```
1. 点击配置
2. 点击右上角的设置
3. 将可见例外中的Android MT2删掉如果有
4. 右上角保存
5. 选择检测软件之类的，比如春秋检测(com.chunqiunativecheck)启动隐藏，右上角点击确认
```

6. 配置cq-uid
*点击执行按钮，添加包名即可*
>这里的`包名`指的是检测软件之类的

7. 在ksu模块管理界面,点击隐藏越狱模式左下角的执行

>注意：该模块是通过zygote重启来实现隐藏的功能,并不是真正意义上的软重启，如果想要加载模块，请先用ksu自带的软重启重启一次，然后用这个重启
